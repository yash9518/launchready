# Esko sample files

This folder holds the two sample files Esko sent to AIForge participants:

- `DancingFish_Granola_Berry_US_Carton_24def4e1.pdf` (artwork, DeskPack dieline proof)
- `DancingFish_Granola_BerryCrunch_US_Content_Sheet_32057df9.xlsx` (US content sheet)

They are included in the source package submitted to HackerEarth. They are left out of the public
repository because they were shared with participants only. If they are missing, copy them here and
restart the app; the "Esko sample" card then appears on the start screen.
